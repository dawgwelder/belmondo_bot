# `/tldr` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/tldr [N]` that fetches recent chat text via Telethon and returns an expanded Belmondo-voice narrative summary via DeepSeek.

**Architecture:** Pure helpers in `tldr/` (parse N, filter messages, build prompt) + `handlers/tldr.py` for Telegram/LLM I/O, registered in `app.py`. Same auth.conf Telethon credentials as godnoscop.

**Tech Stack:** python-telegram-bot, Telethon, AsyncOpenAI (DeepSeek), pytest.

## Global Constraints

- Default N=100, soft max=1000 (clamp + warning)
- Access: `@pause` + `ensure_master_in_chat_for_ai`
- Text-only history; exclude invoking `/tldr` message
- Narrative scene summary (not per-user bullets); Belmondo voice; expanded
- Use chat `ai_lock`; model `deepseek-v4-flash` with streaming like other AI handlers
- Treat chat text as untrusted data
