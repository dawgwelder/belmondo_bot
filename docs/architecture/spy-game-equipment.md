# Конечный ресурс экипировки

Правила для игроков и таблица эффектов находятся в
[руководстве](../spy-game-player-guide.md#предметы-и-экипировка).
Все шесть предметов доступны в трёх общих слотах. Параметры — начальный баланс;
production-метрики отдачи пока не собирались в рамках этой работы.

## Учёт экземпляров

`user_items.amount` остаётся общим числом копий, включая надетую и использованную.
`item_durability` хранит один начатый экземпляр каждого типа на игрока: `remaining`
и `maximum`. `equipped_items` задаёт слот. Надевание всегда продолжает уже начатый
экземпляр; создавать несколько частично изношенных копий одного типа нельзя.

Для обмена доступно общее число копий минус одна, если экземпляр надет **или**
уже потерял хотя бы один заряд. Эти признаки не складываются. Поэтому при двух
копиях и одной изношенной надетой копии обменять можно ровно одну новую.
Просто надевание не портит предмет: снятый экземпляр с полным ресурсом доступен
для обмена. Снятие использованного экземпляра его ресурс не восстанавливает.

`EquipmentRepository.consume` вызывается только в транзакции принятого действия
или выдачи награды. Уникальная запись `equipment_uses` привязана к операции,
игроку и предмету. Повторный вызов не уменьшает ресурс. На последнем заряде
списывается одна копия из `user_items`, удаляются её ресурс и слот. Новая копия
сама в слот не попадает. Ошибка при выдаче награды откатывает и бонус, и износ.

## Где применяются эффекты

- Паспорт: только принятый ход погони, после проверки текущего лидера и лимита.
  Уменьшение срока — уже оказанная услуга, поэтому последующая потеря лидерства
  не возвращает заряд. Следующий ход не удлиняется относительно предыдущего.
- Прослушка: только успешная вербовка, когда выпал бонусный бросок.
- Рация: при финальном расчёте совместной операции, отдельно для каждого владельца.
- Разведданные: после атомарного захвата победы в «Кроте», перед выдачей агентов.
- Снимок: при выдаче тайника, одинаково для inline и HTML5. Пустой результат
  заменяется разведданными; непустой увеличивается на единицу.
- Код доступа: при правильном inline-ответе или выигранной HTML5-сессии перехвата.
  Фактическая награда сохраняется в сессии, чтобы повторное открытие после износа
  предмета показывало тот же результат.

Надевание оценивается в момент действия/выдачи, а не создания общего события.
Эффекты не меняют награды обменов и не работают в Death Mission или дуэлях.
Бонусные предметы — новые копии: они не наследуют износ породившего их предмета.

## Совместимость и интерфейс

Миграция 016 назначает существующей надетой экипировке полный ресурс. Старые
срабатывания до миграции не восстанавливаются задним числом. Осиротевшие слоты,
оставшиеся после старых обменов без фактического предмета, очищаются. Миграция
также восстанавливает награды старых HTML5-перехватов из `event_history`.

Инвентарь Telegram и Mini App показывает общий остаток, остаток экземпляра,
лимит срабатываний, эффект и число новых ненадетых копий для обмена. Telegram
обновляет текст и кнопки после надевания/снятия с сохранением временной очистки
меню в группах. JS/CSS Mini App получили новую версию URL.

В Контрразведке добавлен обмен новой рации и новой прослушки на спутниковый
снимок; редкое NPC-событие сохраняет общий множитель награды ×2.

Локальные проверки охватывают все эффекты, inline/HTML5, повторные и конкурентные
вызовы, снятие/надевание, перезапуск, миграцию, смешанные стеки новых/использованных
копий, границу последнего заряда, откат транзакции и отображение инвентаря.
