# Belmondo Bot 🤖

**Belmondo Bot** - это многофункциональный Telegram бот, созданный для развлечения и взаимодействия в чатах. Бот назван в честь легендарного актера Жан-Поля Бельмондо и включает множество забавных функций, от гороскопов до игр с кубиками.

## 🌟 Основные возможности

### 🎭 Развлечения
- **Гороскопы** - ежедневные предсказания для всех знаков зодиака
- **Цитаты** - случайные мотивирующие и забавные цитаты
- **Кубики** - игральные кости с кастомными настройками
- **Goblin контент** - случайные видео, изображения и тексты
- **Oxxxy плейлисты** - музыкальные рекомендации

### 🎨 Медиа контент
- **Стикеры** - автоматические ответы стикерами на ключевые слова
- **Изображения** - реакция на упоминания слонов, колоколов, нацистов
- **Анимации** - GIF и видео файлы
- **Кастомные ответы** - персонализированные реакции на сообщения

### 🎮 Игры и активности
- **Плотина** - игра в строительство плотины с рейтингом
- **Завод/Офис дня** - ежедневное назначение "работника дня"
- **Специальные команды** - уникальные функции для особых случаев

### 🤖 AI интеграция
- **ChatGPT** - интеллектуальные ответы на сообщения
- **Автоматические промпты** - профессиональные подсказки
- **Контекстные беседы** - запоминание истории разговора

## 🚀 Установка и настройка

### Предварительные требования
- Python 3.8+
- Telegram Bot Token
- OpenAI API ключ (для AI функций)
- Доступ к интернету

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/belmondo_bot.git
cd belmondo_bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Создайте файл `auth.conf` в корневой директории:
```ini
[auth]
openai_api_key = ваш_openai_api_ключ
telegram_bot_token = ваш_telegram_bot_токен
```

### 4. Настройка переменных окружения
Создайте файл `.env` (опционально):
```bash
OPENAI_API_KEY=ваш_ключ
TELEGRAM_BOT_TOKEN=ваш_токен
```

## ⚙️ Конфигурация

### Основные настройки
Бот поддерживает несколько режимов работы:
- **dev** - режим разработки
- **prod** - продакшн режим
- **spam_mode** - настройки защиты от спама:
  - `soft` - мягкая защита
  - `medium` - средняя защита (по умолчанию)
  - `rare` - редкие ответы

### Запуск бота
```bash
# Режим разработки
python main.py --mode=dev --spam_mode=medium --token=YOUR_BOT_TOKEN

# Продакшн режим
python main.py --mode=prod --spam_mode=soft --token=YOUR_BOT_TOKEN
```

## 🎯 Команды бота

### Основные команды
- `/quote` - случайная цитата
- `/horoscope` - выбор знака зодиака для гороскопа
- `/goblin` - случайный goblin контент
- `/oxxxy` - музыкальная рекомендация
- `/day` - стикер дня недели
- `/holiday` - праздники сегодня
- `/zavod` - завод/офис дня
- `/roll` - бросить кубик
- `/plotina` - построить плотину
- `/stats` - статистика плотины
- `/pause` - приостановить/возобновить бота

### Автоматические реакции
Бот автоматически реагирует на ключевые слова в сообщениях:
- **"дембель"** - показывает время до демобилизации
- **"страшно жить"** - отвечает "ВАЩЕ ПИЗДЕЦ"
- **"кубик"** - предлагает бросить кубик
- **"слон"** - отправляет изображение слона
- **"колокол"** - отправляет изображение колы
- **"нацист"** - отправляет соответствующее изображение
- **"джекпот"** - отправляет стикер джекпота с текстом
- **"ой ночи"** - отправляет ночной стикер с пожеланиями

## 🔧 Система триггеров

### Формат триггеров
Триггеры настраиваются в файле `speaking/triggers.json`:

```json
{
  "trigger_name": {
    "triggers": ["ключевое_слово1", "ключевое_слово2"],
    "answers": ["ответ1", "ответ2"],
    "exclude_words": ["исключаемое_слово"],
    "prob": -1,
    "exclude_uids": [123456789],
    "exact": false
  }
}
```

### Типы ответов
- **Текст** - обычные текстовые сообщения
- **Изображения** - `img:путь/к/файлу.jpg`
- **Стикеры** - `img:путь/к/стикеру.webp`
- **Смешанные** - `img:файл.jpg|текст1|текст2`

### Параметры триггеров
- `triggers` - список ключевых слов для активации
- `answers` - возможные ответы (выбирается случайно)
- `exclude_words` - слова, исключающие срабатывание
- `prob` - вероятность ответа (-1 = автоматическая настройка)
- `exclude_uids` - ID пользователей, исключенных из триггера
- `exact` - точное совпадение (true) или частичное (false)

## 🎨 Кастомизация

### Добавление новых триггеров
1. Откройте `speaking/triggers.json`
2. Добавьте новый блок триггера
3. Перезапустите бота

### Создание новых медиа ответов
1. Поместите файл в папку `img/`
2. Добавьте триггер с префиксом `img:`
3. Настройте параметры срабатывания

### Модификация существующих функций
- Основная логика в `main.py`
- Система триггеров в `if_rules.py`
- Утилиты в `utils.py`

## 🐛 Устранение неполадок

### Частые проблемы
1. **Бот не отвечает**
   - Проверьте токен в `auth.conf`
   - Убедитесь, что бот не заблокирован
   - Проверьте логи в консоли

2. **Ошибки с изображениями**
   - Проверьте пути к файлам в `triggers.json`
   - Убедитесь, что файлы существуют в папке `img/`
   - Проверьте права доступа к файлам

3. **AI функции не работают**
   - Проверьте OpenAI API ключ
   - Убедитесь в наличии средств на счете OpenAI
   - Проверьте интернет соединение

### Логирование
Бот ведет подробные логи всех действий. Для включения отладки:
```python
# В logger.py
logging.basicConfig(level=logging.DEBUG)
```
